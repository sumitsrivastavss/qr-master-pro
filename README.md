# QR Master Pro

A professional QR Scanner & QR Generator app built with Flutter. It allows users to scan, generate, and share QR codes with a simple and modern interface.

## ✨ Features
- 📷 QR Code Scanner
- 📝 QR Code Generator
- 📚 Scan History
- 📤 Share QR Codes
- 💡 Flashlight Support
- 🔄 Switch Front/Back Camera
- 🖼️ Scan QR Codes from Gallery
- 🎨 Clean & Modern UI

## 🛠️ Technologies Used
- Flutter
- Dart
- Material 3
- mobile_scanner
- qr_flutter
- share_plus
- image_picker
- url_launcher

## 📱 Platform
- Android

## 🚀 Getting Started

```bash
flutter pub get
flutter run
```
